# Difference entre Git et Github
## Question
Quelle est la difference entre Git et GitHub?
## Reponse
*Git* est un système de contrôle version distribué ( VCS) open-source,installé directement en local sur l'ordinateur du developpeur. son rôle principal est de suivre et d'enregistrer l'historique des modifications apportées au code source au fil du temps.il permet de travailler hors ligne de créer des branches indépendantes pour 
tester des fonctionnalités et de revenir à une version antérieure du projet en cas d'erreur.

*GitHub* est un service web d'hébergement et de gestion de projets informatiques dans le cloud,basé sur le fonctionnement de Git.
il sert de dépôt centralisé en ligne où les développeurs peuvent sauvegarder leur code à distance,le partager et collaborer en équipe grâce à des fonctionnalités dédiées (comme les Pull Requests pour fusionner le code, le suivi des tâches ou la revue de code).
